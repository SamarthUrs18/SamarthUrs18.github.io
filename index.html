Projects

fusion-runtime

Self-hosted voice AI runtime · Apache-2.0 · Python

A single-process STT→LLM→TTS voice agent runtime that streams between stages instead of serialising through network hops, so synthesis begins while the LLM is still generating.

  • ~490 ms turn-end to first audio on an RTX 3090 with a 7B GGUF model, at 127 tok/s.
  • Acoustic echo cancellation written from scratch — STFT filter bank, NLMS adaptive FIR, GCC-PHAT delay estimation — validated at 30 dB suppression, enabling server-side barge-in.
  • A runtime-adapter contract keyed on inference engine, so any Whisper checkpoint or GGUF model runs with zero new code.
  • Deadline-ordered, concurrency-limited scheduler sharing one loaded model across sessions, with a publicly documented degradation curve.
  • Shipped v0.1.0 with a Typer CLI, a browser client over AudioWorklet + WebSockets, Prometheus metrics and CI across Python 3.11–3.13.
